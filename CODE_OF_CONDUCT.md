## 🛠 Feature Breakdown

### Feature 1 — Matrix Construction
Build a 5×5 key square from any keyword, handling duplicates and I/J merging.

### Feature 2 — Digraph Rules
Split plaintext into pairs and handle same-letter and odd-length cases.

### Feature 3 — Encryption
Apply row, column, and rectangle transformation rules.

### Feature 4 — Decryption
Reverse every rule to recover the original plaintext.

### Feature 5 — Test Suite
Verify behavior with pytest and known Playfair test vectors.

### Feature 6 — CLI Tool
Wrap everything in a clean command-line interface.

## 🔧 Troubleshooting

| **Odd-length text** | Pad with X or Z |
| **J missing from matrix** | Merge with I |
| **Matrix index error** | Validate 25 cells |
| **Test failure** | Check test vector case |
| **CLI arg missing** | Print usage message |
